# CityKart — Hamburger Menu Functional Test & QA Verification Report

## 1. Test Environment & Methodology

- **Target Application**: CityKart Intra-City Hyperlocal Marketplace (`http://localhost:3000`)
- **Framework**: Next.js 15 App Router + React 19 + Tailwind CSS + Framer Motion (`motion/react`)
- **Automation Runner**: Headless Chromium via Playwright (`/scripts/audit-hamburger-menu.mjs`)
- **Viewports Tested**:
  - Mobile Portrait: `375×812`
  - Desktop Widescreen: `1440×900`
- **User Roles Tested**:
  1. **Guest** (Unauthenticated visitor)
  2. **Customer / Buyer** (`role: 'buyer'`, `+919876543210`)
  3. **Business Owner / Verified Seller** (`role: 'seller'`, `sellerStoreId: 's1'`, `+919822011111`)
  4. **City Partner** (`role: 'partner'`, `partnerCity: 'Amravati'`, `+919765432109`)
  5. **Super Admin** (`role: 'super_admin'`, `isAdmin: true`, `+918329306616`)
